# 📊 Проект: Дашборд для анализа продаж

Интерактивный дашборд для аналитики продаж, созданный на Python с использованием Pandas и Plotly.
Цель этого проекта — продемонстрировать практические навыки анализа данных, извлечения бизнес-инсайтов и создания дашбордов для сценариев принятия решений в реальных условиях.

## 🛠️ Инструменты и библиотеки
- Python 3
- Pandas – предобработка и трансформация данных
- Plotly – интерактивная визуализация
- Google Colab – среда выполнения блокнотов

## 📁 Набор данных
`sales_data_sample.csv` – вымышленные данные о продажах, включающие:
- Информацию о клиентах
- Линейки продуктов
- Даты заказов
- Выручку и метрики продаж
- Статусы заказов

## 📊 Функции дашборда
### ✔ Динамика выручки по месяцам
Визуальное представление изменения выручки от месяца к месяцу.
### ✔ Топ продуктовых линеек
Идентификация наиболее прибыльных продуктовых категорий.
### ✔ Лучшие клиенты
Ранжирование клиентов, которые приносят наибольшую выручку.
### ✔ Динамическая фильтрация
Легко настраивайте представления и исследуйте различные аспекты данных.

## 💡 Ключевые выводы
### 🔹 Самый прибыльный месяц: Ноябрь 2004
Сильный сезонный спрос указывает на пик продаж в праздничный период.
### 🔹 Лучшая продуктовая линейка: Classic Cars
Доминирует в общей выручке и указывает на высокое предпочтение клиентов.
### 🔹 Главный источник выручки: Euro Shopping Channel
Крупный B2B-клиент, значительно влияющий на общие продажи.

#### *Эти инсайты могут помочь бизнесу оптимизировать управление запасами, маркетинговые кампании и таргетирование клиентов.*
