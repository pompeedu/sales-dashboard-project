# 📊 Проект: Дашборд продаж

Этот проект представляет собой интерактивный дашборд для анализа данных о продажах, созданный на Python с использованием библиотек Pandas и Plotly.  
Он предназначен для демонстрации навыков в области анализа данных, визуализации и работы с реальными бизнес-данными.

## 🛠️ Инструменты и Библиотеки
- Python 3
- Pandas
- Plotly
- Google Colab

## 📁 Набор данных
`sales_data_sample.csv` – вымышленные данные о продажах, включающие:
- Информацию о клиентах
- Линейки продуктов
- Даты заказов
- Выручку

## 📊 Функции дашборда
- Динамика выручки по месяцам
- Топ продуктовых линеек
- Лучшие клиенты по объёму выручки

## 💡 Основные выводы
- Пиковый месяц по продажам: «Ноябрь 2004 года»
- Лучшая продуктовая линейка: «Classic Cars»
- Ключевые клиенты, приносящие наибольшую выручку: «Euro Shopping Channel»

## 🚀 Как запустить
1. Клонируйте репозиторий:
```bash
git clone https://github.com/pompeedu/sales-dashboard-project.git
```
2. Откройте блокнот в [Google Colab](https://colab.research.google.com)
3. Загрузите CSV-файл, если его ещё нет в блокноте
4. Запустите все ячейки, чтобы увидеть дашборд
