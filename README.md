# 📊 Sales Dashboard Project

An interactive sales analytics dashboard built with Python, Pandas, and Plotly.
The goal of this project is to showcase practical data analysis skills, business-oriented insights, and dashboard creation for real-world decision-making scenarios.

## 🛠️ Tools & Libraries
- Python 3
- Pandas – data preprocessing & transformation
- Plotly – interactive visualizations
- Google Colab – notebook environment

## 📁 Dataset
`sales_data_sample.csv` – fictional sales data including:
- Customer information
- Product lines
- Order dates
- Revenue and sales metrics
- Order status
This dataset simulates a realistic e-commerce sales environment.

## 📊 Dashboard Features
### ✔ Monthly Revenue Trend
Visual representation of how revenue changes month-to-month.
### ✔ Top Product Lines
Identification of the most profitable product categories.
### ✔ Top Customers
Ranking of customers that generate the highest revenue.
### ✔ Dynamic Filtering
Easily adjust views and explore different aspects of the data.

## 💡 Key Insights
### 🔹 Highest-grossing month: November 2004
Strong seasonal demand suggests a holiday sales peak.
### 🔹 Best product line: Classic Cars
Dominates total revenue and indicates its high customer preference.
### 🔹 Top revenue contributor: Euro Shopping Channel
A major B2B customer significantly impacting overall sales.

#### *These insights can help businesses optimize inventory, marketing campaigns, and customer targeting.*
