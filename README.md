# 📊 Sales Dashboard Project

This project presents an interactive sales data dashboard built in Python using Pandas and Plotly.  
It's intended to demonstrate skills in data analysis, data visualization, and working with real-world business data.

## 🛠️ Tools & Libraries
- Python 3
- Pandas
- Plotly
- Google Colab

## 📁 Dataset
`sales_data_sample.csv` – fictional sales data including:
- Customer information
- Product lines
- Order dates
- Revenue

## 📊 Dashboard Features
- Monthly revenue trend
- Top product lines
- Best customers by revenue

## 💡 Insights
- Peak month for sales
- Top-performing product line
- Key customers driving revenue

## 🚀 How to Run
1. Clone the repository:
git clone https://github.com/firuzjonq/sales-dashboard-project.git
2. Open the notebook in [Google Colab](https://colab.research.google.com/)
3. Upload the CSV if not already in the notebook
4. Run all cells to see the dashboard
