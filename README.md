# 📊 Sales Analysis Dashboard

This is an interactive dashboard for analyzing company sales data.

## 🛠️ Tools
- Python
- Pandas
- Plotly
- Google Colab

## 🔍 Key Features
- Monthly sales trend
- Top 10 customers
- Product line performance

## 📁 Data
The data comes from `sales_data_sample.csv`.

## 💡 Insights
- Peak sales in November 1, 2004
- Best-selling product line: Classic Cars
- Top customer: Euro Shopping Channel

## 📎 How to Run
You can open this notebook in [Google Colab](https://colab.research.google.com).
